# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:16/11/2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

1. Open the **Autodesk Fusion 360** software.

2. Click on **File → New Design** to create a new design.

3. Select the **XY Plane** and click on **Create Sketch**.
<img width="406" height="666" alt="Screenshot 2026-11-16 015257" src="https://github.com/user-attachments/assets/9df0c3eb-0d22-4681-ac28-f402715c27d5" />

4. Draw a square profile of size **30 mm × 30 mm** using the **Rectangle Tool**.
<img width="76" height="41" alt="Screenshot 2026-11-16 024958" src="https://github.com/user-attachments/assets/63f9eab6-dfc6-414d-9937-8c53cb00a904" />

5. Apply the required dimensions using the **Sketch Dimension Tool (D)**.

6. Click on **Finish Sketch** and use the **Extrude Tool (E)** to create the tabletop with a thickness of **4 mm**.
<img width="146" height="61" alt="Screenshot 2026-11-16 020758" src="https://github.com/user-attachments/assets/a1635456-93c5-44ad-8657-33e21d31acc0" />
<img width="52" height="57" alt="Screenshot 2026-11-16 025216" src="https://github.com/user-attachments/assets/7abf7224-438a-443f-a3b0-bb6e16e1e05c" />

7. Select the bottom face of the tabletop and click on **Create Sketch**.

8. Draw four square profiles of size **2 mm × 2 mm** near the four corners of the tabletop using the **Rectangle Tool**.
<img width="76" height="41" alt="Screenshot 2026-11-16 024958" src="https://github.com/user-attachments/assets/b098996c-0359-48b3-a3fe-49d2885af33e" />

9. Apply the required dimensions and position the four leg profiles properly.

10. Click on **Finish Sketch** and select all four square profiles.

11. Use the **Extrude Tool (E)** to create the four table legs with a length of **30 mm**.
<img width="52" height="57" alt="Screenshot 2026-11-16 025216" src="https://github.com/user-attachments/assets/c833ca7e-9e53-4bf2-a28c-c6c04f1dcb20" />

12. Ensure that all four legs are properly joined to the tabletop.

13. Check the complete 3D table model and verify the dimensions.

14. Save the completed design by clicking **File → Save** and enter a suitable file name.
